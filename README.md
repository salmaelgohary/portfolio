# Salma El Gohary — Product Design Portfolio

A collection of product design case studies and creative work by Salma El
Gohary. The portfolio highlights my approach to designing clear, thoughtful
experiences across complex products and systems.

[View the live portfolio](https://salmaelgohary.com)

## Featured work

- **AMD Install Manager** — Designing a task-first install manager for local AI
- **Trax Copilot** — Making Copilot easier to find, use, and trust in compliance workflows
- **wonderMakr xVend** — Creating an interactive onboarding experience for experiential vending
- Additional work across digital health, mobility, and visual design

## Site highlights

- Responsive layouts for desktop, tablet, and mobile
- Interactive product walkthroughs and before-and-after comparisons
- Motion preferences respected throughout the experience
- Media loaded only when needed to improve performance

## Technology

The site uses semantic HTML, CSS, and vanilla JavaScript, with a small Node.js
build script and no client-side framework or runtime dependencies. It is
deployed on Netlify.

## Repository structure

- `dist/` — production-ready website deployed to Netlify
- `styles.css` — responsive layout, typography, and interaction styles
- `script.js` — navigation, motion, and media interactions
- `media/` — images, videos, illustrations, and supporting assets
- `case-studies/` — source copy for project case studies
- `build.js` — generates the production files in `dist/`
